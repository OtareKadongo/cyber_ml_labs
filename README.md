# Cyber ML Labs 🧪💻

Welcome to the **cyber_ml_labs** repository. This workspace hosts exploratory Python scripts, data processing workflows, and experimental implementations focused on core programming principles, utility tools, and foundational machine learning concepts.

## 🚀 Environment Setup

This project is built and maintained within an **Ubuntu Linux on WSL2** environment. Follow these steps to initialize the workspace locally:

### 1. Clone the Workspace
```bash
git clone https://github.com
cd cyber_ml_labs
```

### 2. Configure Your Virtual Environment
To protect your global system layers, always use a sandboxed `.venv`:
```bash
# Create the virtual environment
python3 -m venv .venv

# Activate the sandbox layers
source .venv/bin/activate
```

### 3. Core Dependencies
Ensure your basic plotting, math tracking, and system processing modules are up to date within your environment:
```bash
pip install --upgrade pip
pip install numpy matplotlib statsmodels scikit-learn
```
